# Onkar Ghugare — Portfolio Website

A responsive, dark-themed portfolio website for an aspiring DevOps Engineer. Built with plain HTML, CSS, and JavaScript; no build step or framework is needed.

## Run locally

1. Download or clone this folder.
2. Open `index.html` in a browser. For a local development server, use VS Code's Live Server extension.

## Personalize before publishing

- Review the LinkedIn URL in `index.html` and change it if your profile URL differs.
- Confirm that each GitHub repository is public and the linked repository URLs are correct.
- Add a professional email address or a downloadable resume link if you want those contact options.
- Adjust the skills and project descriptions to match your current experience before sharing with recruiters.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `onkarghugare08.github.io` for a user site, or `portfolio` for a project site.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. For a project repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site. The Pages settings will show the published URL.

The site uses Google Fonts for typography; if the fonts cannot load, it falls back to system fonts.
